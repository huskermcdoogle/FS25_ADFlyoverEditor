[size=150][b]1.0.3.3 — Settings page fits, wheel zoom check[/b][/size]

[list]
[*][b]The settings page fits the screen.[/b] With a large ui scale the page could run off the screen. It is now never taller than the screen, and everything below the title scrolls, with a scroll bar. While the page is taller than the screen, the mouse wheel scrolls it instead of changing a setting.
[*][b]The launch button stays on screen.[/b] When the side you chose has no room next to AutoDrive's box, the button moves to the other side. It is kept on screen for every position.
[*][b]Leaving the editor puts the screen back on the vehicle you are in.[/b] Before, it went back to the camera from when you opened the editor.
[*][b]New console command: FlyoverWheelReport.[/b] It prints one line about the mouse wheel zoom in a vehicle. If the wheel zoom stops working for you, run it and paste the line into a GitHub issue.
[/list]

Single player only. Requires AutoDrive (tested with 3.0.1.4).
